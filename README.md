# 🏥 Дневник симптомов пациента

Мобильное приложение для пациентов, позволяющее отслеживать медицинские случаи, просматривать назначенное лечение и вести дневник симптомов с возможностью отправки данных врачу.

## 📱 О проекте

Приложение разработано с использованием **React Native** и предназначено для:
- Отслеживания текущих и прошлых случаев обращения
- Просмотра назначенного лечения (название, описание, даты)
- Ведения ежедневного дневника симптомов
- Фиксации ключевых показателей здоровья (температура, давление, пульс)
- Отправки данных врачу для мониторинга состояния

## ✨ Основной функционал

### 🔐 Авторизация
- Простая форма входа с валидацией
- Демонстрационные данные для быстрого старта

### 📋 Список случаев обращения
- Просмотр всех медицинских случаев пациента
- Информация о диагнозе, дате начала и статусе

### 💊 Информация о лечении (Treatment)
- Название и описание терапии
- Даты начала и окончания лечения
- Статус активности лечения

### 📔 Дневник симптомов
- Добавление новых записей с параметрами:
  - Температура тела
  - Артериальное давление (систолическое/диастолическое)
  - Пульс
  - Уровень самочувствия (1–5)
  - Уровень боли (0–10)
  - Симптомы (текст)
  - Жалобы (текст)
  - Комментарий
- История всех записей по каждому случаю

## 🛠️ Технологии

- **React Native** — кроссплатформенная разработка
- **React Hooks** (`useState`, `useMemo`) — управление состоянием
- **Expo / React Native CLI** — сборка и запуск
